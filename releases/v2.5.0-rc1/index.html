粘机场订阅或节点，选格式，一键得到可复制的订阅链接
分享编号

域名白名单在 Worker 变量 CONVERT_HOST_ALLOWLIST 里配置，不在这里。

怎么用（30 秒看完）

1. 把机场给的「订阅链接」粘进输入框；也可以直接粘节点（vless:// / vmess:// / trojan:// / ss://），一行一个，能混着来。
2. 勾你要的格式：Clash 给 Clash/Mihomo/Verge；V2Ray 给 v2rayN/小火箭的 Base64 订阅；Sing-box 给 sing-box；Surge/Loon/Quantumult X/Surfboard 对应各自客户端。
3. 点「生成订阅链接」，每条结果点「复制」，粘到客户端里当订阅地址即可。
4. 链接 2 年有效，期间每次访问自动顺延；不用了可在后台手动失效。
5. 抓取失败看提示：超时/403/不是订阅内容/域名被拦，通常换源或检查链接即可。

Surge / Surfboard / Loon / Quantumult X 的语法未在真机逐一验证，导入失败请换 Clash 或 Sing-box。
