## 项目保护说明

现有正式 Cloudflare D1 数据库和 Worker 必须优先保护。未经用户明确批准，不得破坏性修改数据库、线上数据、密钥或部署环境。文档中的规划不代表已经实现；所有实现状态必须以当前源码和测试证据为准。

## 建议文档目录

- `AGENTS.md`：所有 AI 和开发人员的强制协作规则

- `CHANGELOG.md`：项目文档与实现变更记录
