# 星跃管理平台项目资料库

本仓库用于保存星跃管理平台 V2.5 的项目规范、需求基线、权限规则、实施记录和验收资料。

## AI / 开发人员必读

**开始任何星跃管理平台相关任务前，必须先阅读根目录 `AGENTS.md`，再阅读任务对应的项目文档。**

核心基线：
- [星跃管理平台 V2.5 功能基线与权限验收规范](docs/星跃管理平台V2.5_功能基线与权限验收规范.md)

## 文件归类与版本管理

后续上传、新增和更新的文件统一按模块归档，版本更新放回对应模块目录；原始版本保留，不随意覆盖。具体执行规则见 docs/星跃项目仓库目录归类与版本更新规范.md。

## 项目保护说明

现有正式 Cloudflare D1 数据库和 Worker 必须优先保护。未经用户明确批准，不得破坏性修改数据库、线上数据、密钥或部署环境。文档中的规划不代表已经实现；所有实现状态必须以当前源码和测试证据为准。

## 建议文档目录

- `AGENTS.md`：所有 AI 和开发人员的强制协作规则
- `docs/`：业务需求、权限矩阵、数据生命周期、API 约定、测试验收和版本记录
- `CHANGELOG.md`：项目文档与实现变更记录

敏感凭证、真实订阅 URL、卡密、令牌和数据库密钥不得提交到仓库。
