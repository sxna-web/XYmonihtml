## 1. 本轮确认的字段归属

### 1.1 admin_audit

- 写入语句：`INSERT INTO admin_audit(action, detail) VALUES(..., ?)`（多个路由）。
- 读取语句：`SELECT id, action, detail, created_at FROM admin_audit ORDER BY id DESC LIMIT ?`（Worker 5156 行）。
- 由源码可确认的字段依赖：`id`、`action`、`detail`、`created_at`。
- INSERT 不显式提供 id/created_at，说明写入依赖表端默认/自动生成行为；但仅凭 Worker 不能证明实际 D1 的主键类型、默认值或兼容性。

### 1.2 node_sync_logs

- 写入语句（Worker 1071-1074 行）显式列出：`source_id`、`source_name`、`status`、`total_nodes`、`added_nodes`、`updated_nodes`、`error_message`、`trigger_kind`、`duration_ms`、`missing_nodes`。
- 读取语句（Worker 4905-4911、5190-5197 行）还显式读取：`id`、`created_at`。
- 最低可确认字段集合共 12 项：`id`、`source_id`、`source_name`、`status`、`total_nodes`、`added_nodes`、`updated_nodes`、`error_message`、`trigger_kind`、`duration_ms`、`missing_nodes`、`created_at`。
- 写入未显式提供 `id`、`created_at`，真实 schema 必须提供兼容的自动生成/默认行为；不能据此自行推断其类型。

### 1.3 admin_audit_events

- `auditStmt`（Worker 355-371 行）INSERT 显式写入 11 列：`actor_user_id`、`effective_user_id`、`action`、`target_type`、`target_id`、`request_id`、`before_json`、`after_json`、`result`、`reason`、`detail`。
- 管理端列表（Worker 2214-2215 行）使用 `SELECT * ... ORDER BY id DESC`，故另有 `id` 排序依赖。
- 目前可确认至少 12 个字段依赖，但 `SELECT *` 不能说明表的全部列。INSERT 未显式提供 `id`，同样依赖表端自动生成/默认行为。

## 2. 语句级 bind 抽查

说明：

- 上表只覆盖列出的固定语句，不代表整个 5572 行 Worker 的所有 SQL、所有动态分支和所有 bind 均已完成核验。
- 动态 WHERE、分页、可选筛选和其他路由仍需继续逐语句复核。

## 3. D1 batch 原子性边界

同步提交函数在同一个 `db.batch([...])` 中依次包含：
1. lease fence 断言；
2. task 状态/manifest 断言；
3. node_records set-based upsert；
4. node_identity_aliases upsert；
5. 节点数量完整性断言；
6. 按配置可选的缺失节点停用；
7. node_sync_logs 写入；
8. admin_audit_events 写入；
9. sync_tasks 状态更新；
10. stage 清理；
11. subscription_sync_state 租约收尾。

代码把这些操作组织在一个 D1 batch 中，意图是整批成功或失败。但本轮没有在真实 Cloudflare D1 环境验证 batch 事务行为、约束冲突和生产 schema，因此不能把源码结构描述成生产事务已通过验收。

另一个重要边界：`auditDenied` 和部分独立维护审计采用单独 `.run()`，并捕获失败；它们不属于上面的同步提交 batch，不能宣称所有审计事件都与业务操作原子绑定。

## 4. 本轮结论

- 三张表的已知漏项得到更具体的 SQL 语句证据支持。
- 本轮抽查的 8 类 SQL/bind 组合，数量和位置顺序一致；仅是局部静态核验。
- `admin_audit`、`node_sync_logs`、`admin_audit_events` 的自动生成主键/时间默认值仍须由真实 schema snapshot 证明。
- 22 张 B 类表仍未完成全量逐语句字段矩阵；其余动态 SQL 与 bind 组合尚未全量核验。
- 真实 D1 schema、索引/唯一约束、字段类型、默认值和生产兼容性仍未验证。
- 保持迁移入口 fail closed；不生成生产 CREATE/ALTER SQL，不连接或修改生产 D1。
- RC1 仍是内部候选，不可作为正式生产部署包。
