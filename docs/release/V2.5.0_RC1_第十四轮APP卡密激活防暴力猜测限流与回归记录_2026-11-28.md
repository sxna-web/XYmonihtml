# V2.5.0 RC1 第十四轮：APP 卡密激活防暴力猜测限流与回归记录

- 日期：2026-11-28
- 批次：`V2.5-DEV-B1-APP-REDEEM-RATE-LIMIT-113`
- 范围：仅 APP 公共接口 `POST /api/app/redeem` 的防猜测限流及自动化回归；不改变卡密格式和激活业务规则。

## 实施内容

1. 新增 `checkAppRedeemRateLimit`，复用已存在的 `rate_limits(bucket,count,updated_at)` 表，不新增表、不执行迁移。
2. 固定窗口为 15 分钟；同一 IP 最多 10 次，同一设备最多 5 次。IP 只读取 Cloudflare 边缘注入的 `CF-Connecting-IP`，不信任客户端可控的 `X-Forwarded-For`。
3. IP 与设备标识分别使用 `SESSION_PEPPER` 做 SHA-256 派生，数据库 bucket 不保存明文标识。
4. 通过原子 UPSERT 增加计数，并读取计数判断阈值；过限返回 HTTP 429、`REDEEM_RATE_LIMITED` 和 `Retry-After: 900`。
5. 限流存储异常或计数记录缺失时失败关闭，返回 HTTP 503 `REDEEM_THROTTLE_UNAVAILABLE`，不继续查询卡密或激活。
6. 卡密仍维持原有 16 位生成规则及兼容性；没有修改卡密内容、数据库业务字段或激活批次。
