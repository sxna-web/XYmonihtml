## 2. B 类 22 张 Worker SQL 字段引用表

对当前 RC1 Worker 源码执行字段名词法计数，清单列出的字段名均可在 Worker 文本中找到词法命中。该检查只能排除明显的“字段名完全未出现在源码”情况，**不能**证明字段属于对应表，也不能排除 SQL 别名误配、动态 SQL、字段语义错误或遗漏。

下一步必须按每条 SQL 的 FROM/JOIN/UPDATE/INSERT/DELETE 结构建立：
- SQL 所属路由/函数；
- 表别名到真实表名的映射；
- 每个字段的限定名或可确认归属；
- INSERT 列表与 VALUES 占位符数量；
- bind 参数数量、顺序与表达式来源；
- SELECT/RETURNING 字段是否由调用端实际消费；
- 动态 SQL 分支与可选字段条件。

在上述逐语句矩阵完成前，B 类字段证据等级仍为 `B_WORKER_SQL_FIELD_REFERENCES`，不得生成或执行 CREATE TABLE。
