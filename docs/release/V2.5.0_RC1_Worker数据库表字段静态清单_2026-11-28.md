## 7. 下一步检查规则

- 以 Cloudflare 现有正式 D1 的只读 schema snapshot 为事实来源；仓库历史 DDL 不覆盖真实数据库证据。
- 每张表读取 sqlite_master 定义、table_info、index_list/index_info、foreign_key_list；同时保留 trigger/view 定义。
- 将真实结构与本清单分开存档，输出 missing / extra / incompatible / unknown 四类差异。
- 对字段类型、NOT NULL、默认值、PK、UNIQUE、索引定义不匹配的同名对象标记 BLOCKED。
- 没有用户明确授权，不执行 DDL；不 DROP、不 TRUNCATE、不重建业务表。
- 取得真实 schema snapshot 后，才生成带 migration ID、checksum、依赖和 postcondition 的 D1 迁移计划。
