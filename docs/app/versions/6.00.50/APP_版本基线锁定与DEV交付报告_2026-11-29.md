本次 6.00.50 DEV 源码修改：
1. 新增 `StarJumpEntitlementEntity` 与 Room DAO，以每条 entitlement 独立保存 entitlement/admin/card/expiry/status/token ciphertext。
2. 新增 Android Keystore AES-GCM token vault。
3. 新增旧版单 token 迁移：加密写入、数据库回读并解密验证成功后才清理 SharedPreferences 明文；失败时保留旧值。
4. 主配置数据库 Room 升级至 version 8；显式实现 6→7（补 starJumpBuiltIn 列）和 7→8（新增 entitlement 表及索引）迁移；移除主配置数据库的 `fallbackToDestructiveMigration()`。
5. 激活流程改为保存独立授权记录，不再用新 token 覆盖其他管理员/卡片授权。
6. `/api/app/links` 客户端调用支持重复 `token=` 参数，向后保留单 token 方法。
7. 启动门禁按每条授权独立判断有效期，某管理员的卡密到期不连带判定其他管理员授权到期。
8. 更新 ARM64 构建工作流版本/包名断言到 6.00.50 / com.xingyue.app / versionCode 360。
