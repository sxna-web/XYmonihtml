# Batch 1 来源同步接口调用位置复核更正

- 版本标识：`V2.5-DEV-B1-REVIEW-03`
- 日期：2026-11-27
- 状态：静态复核更正记录

复核 Batch 1 的 `index.html` 后，确认“立即同步”按钮所在函数为 `loadSources()`，其数据来自 `/api/super/sources`，页面包含来源分配、重新分配、解除分配等超管操作。因此该按钮处于超管来源管理界面，不应仅凭 `/api/admin/sync` 路径就直接断言必须替换成用户态 `/api/user/sources/:id/sync`。

**更正结论：**
- `/api/admin/sync` 是否正确，必须结合 Worker 中该路由的超管身份门禁、数据归属及审计要求确认。
- 同一表格中的启停按钮却调用 `/api/user/sources/:id/enabled`，需进一步核实此用户态接口如何处理超管 Session，以及是否会把操作主体/目标 owner 混淆。
- 在没有完整权限测试前，不应把同步按钮直接改成用户态接口，也不应认定当前调用已安全。
- 此更正不影响另一项已确认风险：HTML 的默认 API 地址仍是 staging Worker，首次使用可能连接错误环境；必须在大版本中改为显式环境选择和清晰环境提示。

本更正仅限静态源码核对，未调用 API、未连接 D1、未部署。
